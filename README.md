# 俄罗斯方块

一个纯浏览器运行的俄罗斯方块游戏，单 HTML 文件交付。

## 功能
- 标准俄罗斯方块规则（7-bag 随机器、幽灵落点、踢墙）
- 霓虹视觉风格：发光方块、像素风 SCORE/NEXT/HOLD 面板、深蓝星空背景
- NEXT 预览队列：一次展示后续 3 块，首块高亮
- HOLD 暂存：每块限一次，与暂存区交换
- 消行特效：行闪光、火花粒子、COMBO 连击浮字
- 连击计分：连续消行加成 combo×50×等级，中断清零
- 升级特效：LEVEL 浮字 + 双音提示
- 排行榜：本地保存 Top 10，结算弹窗录入名字，标题栏可随时查看
- Web Audio API 合成音效（可一键静音）
- 难度递增
- 方块颜色主题（经典 / 霓虹）
- 手机端适配：响应式布局、触屏按钮（长按连发）、滑动手势

## 运行
直接双击 `index.html` 打开即可。

## 操作
### 键盘（桌面端）
- ←/→：左右移动
- ↓：加速下落
- ↑/X：顺时针旋转
- Z：逆时针旋转
- 空格：瞬间下落
- C/Shift：暂存当前方块（HOLD）
- P/Esc：暂停/继续
- R：重新开始

### 触屏（移动端）
- 操作按钮共两排（移动端操作统一收口在此，侧栏不再显示重复按钮）：
  - 移动排：◀ ▶ 移动（长按连发）、⟳ 旋转、▼ 加速、⤓ 瞬间下落
  - 操作排：开始、暂停/继续、重开、暂存（HOLD）、主题切换、音效开关
- 棋盘手势：左右滑移动、下滑加速、快速下滑硬降、点按旋转
- 高度自适应：棋盘按 44dvh 封顶（dvh 动态排除浏览器地址栏），整页单屏无滚动；
  老款矮屏（视口高 ≤680px）自动隐藏 HOLD 预览、棋盘降至 34dvh 并进一步收紧间距

## 玩法说明
- 消行得分：1/2/3/4 行分别为 100/300/500/800 ×当前等级
- 连击加成：连续消行第 n 次额外 +（n-1）×50×等级，未消行则中断
- 每消 10 行升 1 级，下落间隔每级 -100ms（下限 100ms）
- 排行榜成绩保存在浏览器 localStorage，不联网
