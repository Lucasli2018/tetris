# 俄罗斯方块

一个纯浏览器运行的俄罗斯方块游戏，单 HTML 文件交付。

## 功能
- 标准俄罗斯方块规则（7-bag 随机器、幽灵落点、踢墙）
- 霓虹视觉风格：发光方块、像素风 SCORE/NEXT/HOLD 面板、深蓝星空背景
- HOLD 暂存：每块限一次，与暂存区交换
- 消行特效：行闪光、火花粒子、COMBO 连击浮字
- 连击计分：连续消行加成 combo×50×等级，中断清零
- Web Audio API 合成音效
- 最高分记录
- 难度递增
- 方块颜色主题
- 手机端适配：响应式布局、触屏按钮（长按连发）、滑动手势

## 运行
直接双击 `index.html` 打开即可。

## 操作
### 键盘（桌面端）
- ←/→：左右移动
- ↓：加速下落
- ↑/X：顺时针旋转
- Z：逆时针旋转
- 空格：瞬间下落
- C/Shift：暂存当前方块（HOLD）
- P/Esc：暂停/继续
- R：重新开始

### 触屏（移动端）
- 操作按钮共两排：
  - 主排：◀ ▶ 移动（长按连发）、⟳ 旋转、▼ 加速、⤓ 瞬间下落
  - 副排：暂存（HOLD）、暂停/继续、重开、主题切换、音效开关
- 棋盘手势：左右滑移动、下滑加速、快速下滑硬降、点按旋转
