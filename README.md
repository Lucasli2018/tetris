# 俄罗斯方块

一个纯浏览器运行的俄罗斯方块游戏，单 HTML 文件交付。

## 功能
- 标准俄罗斯方块规则（7-bag 随机器、踢墙）
- 卡通糖果风格：圆角发光方块、珊瑚橙主题、气泡装饰背景、糖果立体按钮
- 新型方块预览：幽灵落点（半透明虚影，可在设置里开关）
- 特殊玩法：炸弹方块（落地炸掉周围 3×3）、三种游戏模式
- NEXT 预览队列：一次展示后续 3 块，首块高亮
- HOLD 暂存：每块限一次，与暂存区交换
- 消行特效：行闪光、火花粒子、COMBO 连击浮字
- 连击计分：连续消行加成 combo×50×等级，中断清零
- 升级特效：LEVEL 浮字 + 双音提示
- 排行榜：本地保存 Top 10，结算弹窗录入名字
- Web Audio API 合成音效（可一键静音）
- 难度递增
- 方块颜色主题（糖果橙 / 薄荷绿 / 泡泡粉）
- 手机端适配：棋盘尽量占满屏幕、触屏按钮（长按连发）、滑动手势

## 运行
直接双击 `index.html` 打开即可。

## 操作
### 键盘（桌面端）
- ←/→：左右移动
- ↓：加速下落
- ↑/X：顺时针旋转
- Z：逆时针旋转
- 空格：瞬间下落
- C/Shift：暂存当前方块（HOLD）
- P/Esc：暂停/继续
- R：重新开始

### 触屏 / 底部按钮（两端统一）
- 布局统一：分数栏在棋盘上方，NEXT/HOLD 预览在棋盘右侧，操作按钮在棋盘下方（浏览器与手机端一致）
- 方向键 D-pad 两行（与键盘方向键一致）：
  - 上行：⟳ 旋转
  - 下行：◀ 左移、▼ 加速下落、▶ 右移
- 独立的「⇓ 一键下落」按钮（醒目红条，位于方向键下方）
- 左上角齿轮 ⚙ 设置菜单收拢：暂存、重开、模式切换、幽灵开关、炸弹开关、主题、音效、排行榜
- 棋盘手势（移动端）：左右滑移动、下滑加速、快速下滑硬降、点按旋转
- 高度自适应（移动端）：棋盘尽量占满视口（主流机型约 70%~73%），整页单屏无滚动

## 玩法说明
- 消行得分：1/2/3/4 行分别为 100/300/500/800 ×当前等级
- 连击加成：连续消行第 n 次额外 +（n-1）×50×等级，未消行则中断
- 每消 10 行升 1 级，下落间隔每级 -100ms（下限 100ms）
- 排行榜成绩保存在浏览器 localStorage，不联网

### 游戏模式（齿轮设置里切换，切换即开始该模式）
- 经典：标准无尽模式，比拼分数
- 冲刺 40：目标消满 40 行，达成即通关并显示用时
- 限时 120：120 秒倒计时，时间到结算，比拼消行数（结算显示用时）

### 特殊方块
- 炸弹方块（设置开启）：随机出现的 1×1 炸弹块，落地后炸掉周围 3×3 格，可解围或连消
