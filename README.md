# 俄罗斯方块

一个纯浏览器运行的俄罗斯方块游戏，单 HTML 文件交付。

## 功能
- 标准俄罗斯方块规则
- Web Audio API 合成音效
- 最高分记录
- 难度递增
- 方块颜色主题

## 运行
直接双击 `index.html` 打开即可。

## 操作
- ←/→：左右移动
- ↓：加速下落
- ↑/X：顺时针旋转
- Z：逆时针旋转
- 空格：瞬间下落
- P/Esc：暂停/继续
- R：重新开始

## 测试
```bash
node test/logic.test.js
```

逻辑层测试直接从 `index.html` 抽取纯逻辑段运行，覆盖棋盘、方块、旋转、碰撞、消行、计分、难度与状态机。
